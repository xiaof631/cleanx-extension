# Security Policy

## Supported Versions

The current `main` branch is the supported development version.

## Reporting a Vulnerability

Please do not disclose security or privacy issues publicly before maintainers have had a chance to respond.

For now, open a GitHub security advisory if the repository supports it, or contact the project maintainer through the support channel listed on the Chrome Web Store page once available.

Useful details to include:

- Extension version
- Browser and OS version
- A clear reproduction path
- Screenshots or logs if relevant
- Whether the issue involves data exposure, permissions, remote code, or X/Twitter page behavior

## Security Expectations

CleanX should not:

- Upload timeline content or browsing history
- Track users across websites
- Load remote code
- Read authentication tokens
- Call private X/Twitter APIs
- Automate account actions
