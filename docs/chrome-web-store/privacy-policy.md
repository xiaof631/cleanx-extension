# Privacy Policy

Last updated: 2026-05-06

X 清净助手 / CleanX is a browser extension that helps users locally hide low-quality account content on X/Twitter.

## Data Processing

CleanX processes page-visible X/Twitter content locally in the user's browser to decide whether content should be shown, collapsed or hidden.

The extension may locally process:

- Account handles displayed on the page
- Display names displayed on the page
- Text content displayed on the page
- User-managed blacklist and whitelist entries
- Extension settings
- Local filtering statistics
- Recent risky account records

## Data Storage

CleanX stores settings, blacklist, whitelist, statistics and recent risky account records in `chrome.storage.local`.

## Data Sharing

CleanX does not upload, sell, rent, transfer or share user data with the developer or any third party.

## Tracking

CleanX does not track users across websites and does not collect browsing history.

## Remote Services

CleanX V0.1 does not use remote classification services, remote APIs or remote code.

## Contact

Contact information will be provided on the Chrome Web Store listing or project support page.
