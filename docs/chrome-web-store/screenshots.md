# Screenshot Guide

Use real screenshots from the loaded extension before submitting to Chrome Web Store.

## Recommended Screenshots

1. Popup enabled state
   - Show CleanX enabled.
   - Show today's hidden count, risky account count, restore count and list count.
   - Show filter strength controls.

2. Options page
   - Show settings, hide mode and filter strength.
   - Show blacklist and whitelist management.

3. Recent risky accounts
   - Show the `最近风险账号` section with at least one risk account if available.
   - If there is no natural risky content, add a visible account to blacklist and refresh X/Twitter.

4. X/Twitter placeholder
   - Show a hidden content placeholder on an X/Twitter page.
   - Make sure no private messages, personal account data or sensitive content is visible.

## Capture Notes

- Keep screenshots clean and focused.
- Avoid showing private timelines, private messages or personal data.
- Use the same language as the store listing.
- Prefer full browser screenshots over heavily cropped UI fragments.

## Store Upload

Chrome Web Store will show the exact image requirements in the Developer Dashboard. If a screenshot is rejected, resize it according to the dashboard message and upload again.
