# Chrome Web Store Listing

## Title

X 清净助手 - X 信息流净化工具

## Short Description

本地自动隐藏 X 信息流和评论区中的低质账号、垃圾营销和重复内容。

## Detailed Description

X 清净助手是一款面向 X/Twitter 网页端的浏览器扩展，帮助你减少信息流、评论区和搜索结果中的低质量账号内容干扰。

它会在浏览器本地扫描页面内容，根据可解释的本地规则识别疑似垃圾营销、重复评论、异常导流和低质量账号，并按你的设置进行隐藏、折叠或模糊处理。

主要功能：

- 自动净化 X 首页时间线
- 自动处理评论区中的低质量内容
- 支持搜索结果页面
- 支持本地黑名单
- 支持本地白名单
- 支持误判恢复
- 支持轻度、标准、严格三档过滤强度
- 支持隐藏、折叠、模糊三种处理方式
- 支持本地统计和最近风险账号查看
- 支持配置导入和导出

隐私边界：

- 不调用 X/Twitter 非公开接口
- 不自动拉黑或静音账号
- 不上传用户时间线内容
- 不上传浏览记录
- 不做跨站跟踪
- 所有设置、名单和统计默认保存在浏览器本地

适合希望降低信息流噪音、减少垃圾营销和提升 X 浏览效率的用户。
